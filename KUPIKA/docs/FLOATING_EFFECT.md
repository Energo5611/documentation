# Обязательное уточнение: послойный объём и парение

Дата: 10.10.2026. Последние слова владельца: «магазин листочки должны быть как бы на разных уровнях». Это уточнение имеет приоритет над плоскими изображениями старых бренд-постеров. Не изменяет функции приложения.

## 1. Визуальный результат

Не плоская картинка с одной общей тенью. Логотип воспринимается как маленькая объёмная композиция: светлая подложка, три листовидных элемента на разной глубине и небольшой французский магазинчик впереди. Под иконкой — мягкая рассеянная тень с заметным воздушным зазором. Элементы слегка перекрываются и отбрасывают индивидуальные тени, объясняющие глубину.

Магазин остаётся главным передним объектом, листочки обрамляют его позади. Утверждённые форма, цвета и фронтальная композиция узнаваемы; это объёмная версия единого логотипа, не новый знак. Нельзя менять форму листьев, пропорции магазина или размещение букв ради эффектной анимации.

## 2. Предлагаемые уровни

Числа — стартовые дизайн-параметры, не обязательная физическая модель. Для сцены шириной 160–220 CSS px:

| Слой | Относительная глубина | Поведение |
|---|---|---|
| Поверхность под иконкой и рассеянная тень | 0 | Неподвижная опора |
| Сливочная скруглённая подложка | 0–4 | Мягкая толщина и блик по краю |
| Дальний шалфейный листочек | 8 | Самое слабое смещение |
| Пудровый листочек | 15 | Среднее смещение |
| Бежевый листочек | 22 | Чуть ближе и отдельная тень |
| Фасад французской лавки | 32 | Передний план |
| Полосатая маркиза лавки | 36 | Небольшой выступ относительно фасада |

Видимую толщину делать деликатной: матовая керамика/плотная бумага, не металлический bevel и не пластиковая игрушка. Маркиза может иметь собственную неглубокую тень. Солнечный свет условно сверху слева; тени всех элементов согласованы по направлению. Чем дальше предмет от принимающей поверхности, тем мягче его тень. Чёрные тяжёлые контуры запрещены.

Различие уровней должно читаться В ПОКОЕ. Параллакс не заменяет хорошую статическую композицию.

## 3. Ассеты и реализация

Нужны раздельные слои с прозрачностью и единым canvas/viewBox: base, leaf-sage, leaf-powder, leaf-beige, shop-facade, shop-awning, отдельная надпись. Для каждого согласовать anchor, исходную позицию, локальную тень и порядок перекрытия. Не нарезать автоматически прямоугольные фрагменты постера с остатками фона.

Целевой компонент `LayeredBrandMark`. Внутри приложения допустимы SVG/прозрачные WebP-слои и CSS transform/perspective; полноценный WebGL не обязателен. Если используется CSS 3D, проверить, что opacity/filter/overflow на родителях не схлопывают нужный preserve-3d-контекст. Тени можно вынести в отдельные соседние слои, а не накладывать тяжёлый filter на весь контейнер [S19].

Отдельно экспортировать статическую композицию для системной иконки и упрощённый знак для маленького размера. Не заявлять, что такие исходники уже существуют: в архиве постеры-референсы, раздельные мастер-слои предстоит подготовить.

## 4. Реакция внутри приложения

При наведении мыши или коротком касании — очень небольшое изменение угла, максимум 2–3 градуса, и относительное смещение слоёв ориентировочно 1–4 px. Фасад движется сильнее дальних листьев, тень остаётся связанной с поверхностью. После ухода/отпускания — плавный возврат 220–320 мс. Смещение не должно мешать нажать нужную кнопку.

При нажатии вся композиция чуть приближается к подложке: ощущение мягкого прижатия, не провал и не подпрыгивание. Не перехватывать вертикальную прокрутку пальцем; не включать гироскоп без отдельного запроса. В покое все слои неподвижны. Reduced motion отключает параллакс и декоративные трансформации, но статический объём и тени сохраняются [S08].

Для товарных карточек применять тот же принцип мягкого подъёма умеренно: поверхность карточки ниже изображения продукта, аккуратная индивидуальная тень продукта. Текст расположен стабильно и не плавает отдельно от карточки. Все товары не должны постоянно двигаться.

## 5. Где эффект работает

В интерфейсе приложения, на заставке/в профиле/презентации возможны настоящие раздельные слои и интерактивная реакция.

Для иконки установленной PWA объём запекается в статическое изображение. CSS приложения не управляет послойным движением и внешней тенью иконки на домашнем экране телефона. Не обещать параллакс iOS из веб-приложения. Подготовить обычную, maskable и Apple-touch версии; учитывать системную маску. Не использовать изображение с большой внешней тенью и маленьким квадратом внутри как единственный launcher-ассет [S18].

## 6. Критерии приёмки

- [ ] Магазин и все три листочка имеют различимую глубину, а не лежат в одной плоскости.
- [ ] Есть индивидуальные согласованные тени и мягкий зазор под иконкой, без грязных чёрных ореолов.
- [ ] В покое видно объём; при небольшом движении видно различие скоростей слоёв.
- [ ] Один и тот же layered-ассет используется во всех темах; логотип не перекрашивается динамическим фоном.
- [ ] Маленькая иконка читаема; системная маска не обрезает магазин и ключевые части.
- [ ] Параллакс не мешает прокрутке/нажатию, отключается при reduced motion, не работает бесконечно в idle.
- [ ] Есть статический экспорт и раздельные исходники; плоский PNG не выдан за редактируемую послойную сцену.

Подготовить фронтальный вид, слегка наклонённый вид и диагностическую раскладку слоёв для согласования. На основной демонстрации слои собраны вместе, а не разнесены в техническую схему.
