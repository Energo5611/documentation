# Статус передачи проекта

10.10.2026 • пакет 1.2.

## Подготовлено

Полное модульное ТЗ, инструкции AGENTS/START_CODEX, правила телефонного входа/приглашений и разных семей, дизайн-система трёх тем, послойный логотип, общий динамический фон, конвейер голосового ассистента с выбором 3D-товаров, примеры данных и чек-листы приёмки. Текстовые материалы размещены в отдельной GitHub-ветке. Визуальные PNG-референсы предоставляются отдельным архивом.

## Не реализовано этим пакетом

Клиент, сервер, настоящий телефонный вход, отправка SMS/push, распознавание речи, resolver моделей, база семей, код синхронизации, готовые мастер-SVG/GLB/раздельные слои. Planned-ID и null-пути в JSON не являются файлами моделей.

## Тесты

Проверена публикация документов. Проверки приложения, голосов, телефонов и устройств: NOT RUN, поскольку кода приложения в этом пакете ещё нет. Чекбоксы ACCEPTANCE.md не отмечать выполненными на основании наличия документации.

## Решения до production

Сервер/домен; безопасное подтверждение номера и восстановление; провайдер/бюджет SMS либо иной согласованный способ; ресурсы STT/NLU; подготовка реальных моделей и лицензий; политика данных и детские профили; финальная визуальная приёмка.

Дальше Codex обновляет этот файл по этапам M0–M3 с фактами, результатами выполненных команд и перечнем NOT RUN. Не объявлять завершённым то, чего нет.
