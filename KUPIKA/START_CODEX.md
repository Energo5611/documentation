# Задание для запуска Codex

Открой каталог KUPIKA из ветки codex/kupika-spec-v1 репозитория Energo5611/documentation. Прочитай AGENTS.md и все документы, перечисленные в README.md.

Разработай «Купика / KUPIKA» — мобильную PWA для разных независимых семей. Первый вход по телефону: фиксированный +7 и 10 цифр; приглашения по номеру с обязательным принятием. Не использовать номер как единственный секрет. Способ проверки владения номером и стоимость провайдера согласовать перед публичным запуском; в демо использовать только изолированные тестовые аккаунты.

Главное: общие списки, крупные 3D-карточки БЕЗ ЦЕН, ввод текстом, надиктовка с предпросмотром, отдельные аудиосообщения, серверная синхронизация, офлайн-очередь, уведомления, дети с родительскими разрешениями. Муж/жена не фиксированные роли.

Один логотип — маленький французский магазинчик и три листочка на РАЗНОЙ ГЛУБИНЕ с индивидуальными тенями. Магазин впереди. Нужны раздельные исходные слои, статический экспорт и компонент LayeredBrandMark. Внутри приложения допустима деликатная реакция слоёв; на домашнем экране телефона это статическая иконка, не CSS-анимация.

Три отличимые темы: «Север», «Пудра», «Солнечная». Женская пудровая, не ярко-розовая. Эффект стекла и парящих карточек. При покупке общий фон всего экрана мягко меняется в цвет продукта. «Люблю! Целую.» отправляет список/сообщение, не закрывает список.

Начни с аудита текущих файлов и плана M0. Выполняй этапы ТЗ, не останавливаясь на описании, когда код можно реализовать. M0 — кликабельный дизайн трёх тем и слоистый логотип; M1 — две независимые семьи, вход, приглашения, общий список и настоящая синхронизация; M2 — голос, дети, PWA/push; M3 — устройства, безопасность, доступность, эксплуатация.

Не менять соседние проекты. Локальные файлы сохранять в согласованной папке внутри «Мои проекты», проверив путь. Не покупать сервисы и не публиковать реальные данные без согласия. Версии зависимостей проверить и закрепить в lockfile.

На каждом этапе предоставляй работающий preview, когда доступна реальная среда, либо точную проверенную команду локального запуска. Приложи скриншоты, результаты тестов и непроверенные пункты. Не выдумывать URL, успешные тесты, готовые 3D-ассеты или доставку уведомлений.

PNG-референсы находятся в отдельном архиве из переписки; запросить его, если он не приложен к окружению, до финальной визуальной приёмки. В текстовом репозитории есть описание приоритетов и размеров, но нет готовых раздельных слоёв логотипа.
