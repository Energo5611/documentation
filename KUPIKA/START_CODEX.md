# Стартовое задание для Codex

Скопировать текст ниже в задачу Codex, открыв рабочий каталог `KUPIKA` либо передав путь к нему.

---

Разработай семейное мобильное веб-приложение «Купика / KUPIKA» по материалам этого каталога. Прочитай AGENTS.md, README.md, полное ТЗ в docs/TECHNICAL_SPEC.md, docs/DESIGN_SYSTEM.md, docs/ACCEPTANCE.md и references/README.md. Текстовые требования выше по приоритету, чем случайные детали на изображениях.

Это НЕ интернет-магазин. Нужны общие списки с крупными 3D-карточками БЕЗ ЦЕН, голосовая надиктовка, отдельные аудиосообщения, уведомления и синхронные отметки покупки. Все взрослые равноправны в покупках. Родители могут подключать детей с ограниченными правами.

Используй единый логотип с небольшим французским магазинчиком и три заметно разные темы — «Север», «Пудра», «Солнечная». Женская тема спокойная пудровая. Стекло, мягкие тени, ощущение парящих карточек. Не воспроизводи один интерфейс с едва изменённым оттенком для мужского и детского профиля.

При отметке покупки общий фон всего экрана мягко переливается в основной оттенок продукта: молоко — сливочный, хлеб — песочный, сыр — мягкий золотистый, зелень — шалфейный. Логотип и читаемость остаются неизменными. Динамический фон — обязательная функция, а не необязательная декорация.

Кнопка «Люблю! Целую.» отправляет список/сообщение близким и НЕ завершает список. Новые позиции можно добавлять во время похода в магазин.

Начни с проверки репозитория и текущей реализации. Не меняй соседние проекты. Для локальной работы найди согласованный каталог внутри «Мои проекты»; не придумывай путь. Зафиксируй выбранные версии и допущения в docs/DECISIONS.md.

Затем выполни этапы из ТЗ:
- M0: дизайн-компоненты и кликабельный локальный прототип трёх тем. Покажи главный экран, добавление, покупку с фоновым переливом, запись голоса и семью. Локальную имитацию помечай как демо.
- M1: настоящий вертикальный сценарий двух пользователей — вход, семья, общий список, добавление и покупка с серверной синхронизацией, восстановлением связи и обработкой конфликтов.
- M2: голосовые сообщения, серверное распознавание русского списка с предпросмотром, Web Push/PWA и детские права.
- M3: визуальная доводка, доступность, безопасность, тесты реальных устройств, инструкция запуска и резервного копирования.

Не останавливайся на описании плана, когда реализацию этапа можно выполнить в доступной среде. При этом не объявляй завершённым то, что требует согласования или проверки на устройстве. Платные подключения, реальные домены и публичный запуск — только после согласования.

В конце каждого этапа дай ссылку на работающий preview, когда среда позволяет его создать, либо точную команду локального запуска. Приложи скриншоты и отчёт о тестах. Не выдумывай адрес preview.

## Важное о материалах

В GitHub находятся текстовое ТЗ и вспомогательные файлы. PNG-референсы есть в отдельном архиве с материалами из переписки. Если они не приложены к среде Codex, попроси архив до финальной доводки логотипа. Не утверждай, что получил готовый SVG или отдельные 3D-модели: в пакете референсы-постеры, а исходные ассеты предстоит подготовить.
