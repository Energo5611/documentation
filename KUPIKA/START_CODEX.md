# Стартовая задача для Codex — пакет 1.2

Открой `KUPIKA` в ветке `codex/kupika-spec-v1` репозитория `Energo5611/documentation`. Прочитай AGENTS.md, README.md и ВСЕ перечисленные обязательные документы, особенно новое docs/VOICE_ASSISTANT_3D.md.

Разработай «Купика / KUPIKA» — мобильную PWA для разных независимых семей. Вход по телефону: +7 предустановлен, 10 цифр. Приглашение по номеру только с принятием. Номер не использовать как единственный секрет; способ проверки и расходы согласовать до public release, демо на изолированных тестовых аккаунтах.

Основной сценарий: общий список, крупные карточки БЕЗ ЦЕН, текст/голос, синхронные покупки, офлайн-очередь, уведомления, детские разрешения. Любой взрослый составляет список и покупает. «Люблю! Целую.» отправляет, но не закрывает список.

Голосовой ассистент не должен останавливаться на транскрипции. Фраза «два пакета молока по литру, батон и зелёные яблоки» должна дать осмысленные позиции и автоматически подходящие 3D-ассеты. Нужны ProductIntentParser, ProductResolver, ProductVisualResolver и исправляемый предпросмотр. Батон не заменять багетом, зелёное яблоко красным. Неизвестное/неоднозначное уточнять либо использовать честный нейтральный fallback.

Подготовить реестр approved-моделей с версиями, GLB и рендерами. В сетке лёгкие WebP/PNG из моделей, 3D-просмотр в деталях по потребности. Не объявлять PNG настоящей моделью, не выдавать planned/null-пути за готовые ассеты. Не запускать новую платную генерацию для каждого запроса. Приватные семейные соответствия и предпочтения не смешивать. ambientColor берётся из выбранного варианта.

Единый логотип: магазинчик французской лавки впереди, три листочка позади на разных уровнях с индивидуальными тенями. Раздельные исходные слои, статический экспорт и LayeredBrandMark внутри приложения. Системная иконка телефона остаётся статичной. Три разные темы: «Север», «Пудра», «Солнечная», женская спокойная пудровая. Стекло и парение; покупка плавно меняет общий фон всего экрана в цвет продукта.

Начни с аудита и M0; выполняй доступный этап, не ограничивайся планом. M0 — кликабельные три темы, слоистый логотип, визуальный подбор на тестовом каталоге. M1 — сервер, разные семьи, приглашения, синхронизация и реестр ассетов. M2 — реальный голос, понимание/уточнения/подбор модели, дети, PWA/push. M3 — реальные устройства, безопасность, верификация номера, готовые модели/лицензии, эксплуатация.

Не менять соседние проекты. Локальный путь — согласованная папка «Мои проекты» после проверки. Не покупать сервисы, не отправлять реальные SMS и не публиковать частные данные без согласия. Версии проверить и закрепить lockfile.

После этапа — рабочий preview, если он фактически доступен, либо проверенная команда локального запуска, скриншоты, результаты тестов и NOT RUN пункты. Отдельно перечень реально готовых GLB/рендеров и отсутствующего. Не выдумывать URL, тесты, ассеты или доставку уведомлений.

PNG-референсы находятся в отдельном архиве переписки. Передать папку references в среду Codex для визуальной приёмки. Текстовое ТЗ выше случайных цен/устаревших элементов на исходных постерах.
