# Купика / KUPIKA — полное задание для Codex

**Версия 1.1 • 10.10.2026.** Мобильное веб-приложение для разных семей. Это пакет требований, а не готовое приложение.

## Начать

Прочитать [AGENTS.md](AGENTS.md), выполнить [START_CODEX.md](START_CODEX.md). Основной документ — [полное ТЗ](docs/TECHNICAL_SPEC.md). Обязательно также прочитать [вход по телефону и приглашения](docs/PHONE_AND_FAMILIES.md), [дизайн-систему](docs/DESIGN_SYSTEM.md), [послойный объём логотипа](docs/FLOATING_EFFECT.md), [приёмку](docs/ACCEPTANCE.md).

## Последние решения владельца

- Приложение для многих независимых семей, не только для семьи автора.
- Первый вход по номеру: фиксированный +7 и ещё 10 цифр. Приглашение в семью — по номеру; получатель обязательно принимает его. До принятия доступа нет.
- Номер служит идентификатором, не безопасным секретом. Подтверждение номера для публичной версии — предлагаемое техническое решение; канал, провайдер и расходы согласуются отдельно. Email-вход из первого черновика отменён.
- Общие списки, большие 3D-карточки, ручной ввод, надиктовка, отдельные аудиосообщения, уведомления, синхронные покупки. Все взрослые равноправны в покупках; дети имеют отдельные разрешения.
- Никаких цен, сумм, скидок, оплаты и доставки.
- Три различимые темы: мужская, женская пудровая, детская. Логотип один для всех.
- При покупке общий фон мягко принимает оттенок продукта.
- «Люблю! Целую.» отправляет список/тёплое сообщение, но не закрывает список.
- Логотип — французский магазинчик и три листочка НА РАЗНЫХ УРОВНЯХ. Магазин впереди, листья сзади на разной глубине, индивидуальные мягкие тени и ощущение парения. Не плоская картинка с одной тенью.

## Состав

`docs/TECHNICAL_SPEC.md` — функции, экраны, данные, API, синхронизация, безопасность, этапы.

`docs/PHONE_AND_FAMILIES.md` — сценарии +7, безопасность входа, приглашения, независимые семьи.

`docs/DESIGN_SYSTEM.md`, `docs/FLOATING_EFFECT.md`, `design/tokens.json` — визуальные правила и параметры.

`docs/ACCEPTANCE.md`, `data/voice-cases.json`, `data/products.seed.json` — критерии проверки и демонстрационные данные без цен.

`docs/SOURCES.md` — первичные технические источники. `.env.example` — только имена настроек, без секретов.

`references/README.md` — приоритеты визуальных референсов. PNG-постеры передаются в отдельном архиве из переписки. В GitHub размещены текстовые инструкции и данные, а не готовые векторные/послойные исходники логотипа.

Приоритет: последние явные требования владельца → ТЗ и профильные дополнения → токены → PNG-референсы → ранние концепции. Случайные цены и магазинные кнопки на постерах НЕ переносить.

## Работа с репозиторием

Ветка `codex/kupika-spec-v1`, каталог `KUPIKA`. Соседние проекты и основную ветку не менять. Для локальной разработки использовать согласованный каталог внутри «Мои проекты», проверив фактический путь. Этот пакет не устанавливает платные сервисы, не отправляет SMS и не публикует реальные семейные данные.

До запуска согласовать домен/сервер, способ подтверждения номера, условия хранения данных, ресурсы распознавания и финальные мастер-ассеты. Красивый прототип не является публично готовым приложением.
