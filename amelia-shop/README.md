# Amelia Shop — ТЗ для Codex

**Целевой сайт:** https://amelia-shop.ru  
**Источник каталога:** https://vk.ru/ameliashoplove  
**Версия:** 1.0 · 6 октября 2026 года

Пакет задаёт создание современного интернет-магазина Amelia Shop с приоритетом телефона, полноценной версией для компьютера, авторским дизайном и аккуратной motion-анимацией.

## Что читать

1. [SPEC.md](SPEC.md) — полное техническое задание: продукт, дизайн, контент, архитектура и этапы.
2. [ACCEPTANCE.md](ACCEPTANCE.md) — проверяемые условия готовности.
3. [RESEARCH.md](RESEARCH.md) — актуальные исследования и обоснование решений.
4. [CODEX_TASK.md](CODEX_TASK.md) — готовое задание для запуска работы в Codex.

**Главный документ — SPEC.md.** Остальные уточняют его. Новые прямые указания владельца имеют приоритет.

## Два этапа

**Демо:** реальные изображения и описания из группы VK сохраняются в локальный набор данных. Поиск, каталог, карточки и корзина работают без ключа VK API. Завершение сценария — подготовка списка товаров и переход в VK для уточнения заказа.

**После получения API:** серверная синхронизация обновляет тот же каталог через отдельный адаптер. Интерфейс и товарные адреса сохраняются. Оплата и полноценное оформление заказа — отдельный этап после получения бизнес-условий и доступов.

## Запуск задания

Передайте Codex ссылку на эту папку и текст из CODEX_TASK.md. Попросите прочитать все пять документов и выполнить этап демо.

Ветка пакета: **amelia-shop-spec**. Папка: **amelia-shop/**. В репозитории есть другие проекты; они не относятся к этому ТЗ.

Чтобы скачать только документы через Git:

~~~bash
git clone --filter=blob:none --sparse --single-branch --branch amelia-shop-spec https://github.com/Energo5611/documentation.git amelia-shop-brief
cd amelia-shop-brief
git sparse-checkout set amelia-shop
~~~

Либо откройте SPEC.md на GitHub и используйте **Raw / Download raw file**.

## Что уже сделано в этом пакете

ТЗ и критерии составлены, первичные источники изучены на 06.10.2026. Это пакет документации, а не исходный код готового нового магазина.

Содержимое VK при подготовке ТЗ не удалось проверить из среды исследования. Поэтому здесь нет якобы импортированных товаров, подтверждённых актуальных цен или обещания работающей API-синхронизации. Порядок получения реального демо-контента и действия при недоступности VK определены в SPEC.md.
